# Основная информация

**Название**: CLI-заметки
**Суть**: Управление заметками
___
# Структура

### Хранение

***Файл***: data/notes.json (**путь от файла скрипта**)
***Представление***: Список словарей, где каждый словарь представляет отдельную заметку и имеет
> *id*: Индивидуальный номер -> int
> *name*: Имя заметки -> str
> *content*: Содержание заметки -> str

### Логика

***Файл***: src/projects/notes/notes.py
**Задачи**:
- Первоначальное чтение и последующие обновления файла, хранящего заметки
- Добавление, изменение, удаление задач и другие манипуляции
- Реализация поиска по имени и по id
- Валидирование логических данных
### Главное управление

***Файл***: src/projects/notes/main.py
**Задачи**:
- Приветствие и краткая инструкция по использованию
- Обработка пользовательского ввода
- Выполнение команд вызовом функций
- Валидирование типов данных
___
# Функции

- `load_notes(path)`
	  Загрузка заметок из файла -> `list` заметок | `[ ]`
- `save_notes(path, notes)`
	  Сохранение заметок в файл -> `None`
- `add_note(notes, name, content, path)`
	  Добавляет заметку в список -> id
- `delete_note(notes, note_id, path)`
	  Удаляет заметку по id -> `True/False`
- `edit_note(notes, note_id, new_content, path)`
	  Изменяет контент заметки -> `True/False`
- `find_by_name(notes, name)`
	  Ищет заметки с переданным именем -> `list` заметок | `[ ]`
- `find_by_id(notes, note_id)`
	  Ищет заметку по id -> Заметка (`dict`) | `None`

***Важно***: Функции, изменяющие список задач должны вызывать `save_notes()`

# Нюансы

- **id уникален:** Новый id это `max(существующих) + 1`
- **Хранение CS:** Сохранять заметки с тем же регистром а искать по нижнему
- **JSON:** Если файла - нет создать пустой
- **Выход:** Обработка KeyboardInterrupt, выход через команду `quit`
- **Поиск:** Поиск по имени частичный
- **Пустое имя:** ValueError
- **Пустой контент:** Норма
- **Пустой битый файл:** Ошибка
- **Поиск по пустой строке:** При вводе find без аргумента выводиться **все** заметки
- **Флаг в поиске:** У функции find есть флаг --more
- **в CLI:** имя аргументом, контент через input
